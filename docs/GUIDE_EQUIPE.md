# Plateforme ALGERAC — Guide équipe (Ali, Karim, Nabil)

**1. Votre compte**
- Brahim crée votre compte avec votre adresse **@calibraes.com** et vous remet un mot de passe provisoire (en main propre ou par téléphone, jamais par e-mail).

**2. Se connecter**
- Ouvrez **https://bbelkhodja-spec.github.io/calibra-algerac-tracker/**
- Saisissez votre adresse @calibraes.com et le mot de passe provisoire.
- Première connexion : en bas du menu, **Changer mon mot de passe** (12 caractères minimum, personnel).

**3. Travailler**
- **Mes tâches** : vos tâches, les retards en premier.
- Cliquez une tâche : lisez **Pourquoi** et **Comment faire**, suivez les étapes.
- **Démarrer** quand vous commencez, **Marquer terminé** quand le livrable existe.
- Joignez toujours la **preuve** (bouton Téléverser : Word, Excel, PDF, photo… 50 Mo max).
- Bloqué ? **Signaler un blocage** + une phrase d'explication.
- ALGERAC envoie un document ou fixe une date ? Notez-la dans **Dates ALGERAC**.

**Règles** : les cartes violettes « Décision » sont validées par le décideur indiqué. Un ⚠ rouge = délai officiel ALGERAC.
Si un message « Modifié par … entre-temps » apparaît : quelqu'un a changé la même fiche au même moment ; rien n'est perdu, refaites simplement votre modification.
